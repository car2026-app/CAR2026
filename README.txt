CAR2026 - PROTOTIPO IPHONE 0.2

IMPORTANTE
Esta version es una PWA de pruebas. El listado de estaciones y las fechas/horas de ejemplo NO son datos reales. Todavia no consulta la agenda de VEIASA ni reserva citas.

COMO PROBAR EN IPHONE
1. Publica el contenido de esta carpeta en un alojamiento HTTPS (por ejemplo, un hosting web propio).
2. En el iPhone, abre la URL publicada con Safari.
3. Pulsa Compartir > Anadir a pantalla de inicio > Anadir.
4. Abre CAR2026 desde el nuevo icono.

La instalacion PWA en iPhone requiere servir la app desde HTTPS. Abrir index.html directamente desde Archivos no permite instalarla como app web.

FUNCIONES DE ESTA VERSION
- Matricula obligatoria.
- Segundo dato opcional entre fecha de primera matriculacion o seis ultimos digitos del bastidor.
- No solicita NIF.
- Flujo provincia > estaciones > calendario demostrativo.
- Acceso al portal oficial https://www.itvcita.com/Welcome.do para que el usuario complete el proceso y el CAPTCHA.
- No guarda los datos del vehiculo ni los envia a un servidor de CAR2026.

PENDIENTE
- Sustituir estaciones de ejemplo por el directorio oficial validado.
- Investigar un mecanismo permitido para consultar disponibilidad real.
- Incorporar alertas solo cuando exista una fuente fiable de disponibilidad.
